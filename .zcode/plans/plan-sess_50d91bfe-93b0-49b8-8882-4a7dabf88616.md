# Claude 订阅额度:两层回退链 + 同意门控(Codex 仅小补丁)

## 目标

把 Claude 订阅额度的采集从「纯本地文件」升级为**三层回退链**(前两层即用户确认的 OAuth + CLI,第三层为现有本地逻辑,零新增成本地保留兜底):

1. **官方 OAuth 接口**(新,主力):`GET https://api.anthropic.com/api/oauth/usage`,借 Claude Code 存在 macOS 钥匙串里的登录凭证,带用户同意门控。
2. **CLI 探测**(新,兜底):portable-pty 真终端拉起 `claude`,输入 `/usage`,解析屏幕文字。
3. **现有本地采集**(保留,最后兜底):Desktop `plan-usage-history.json` + statusline 桥,代码不动。

Codex 侧本阶段只做三个后端小补丁:legacy 路径 token 自动续期、`chatgpt_base_url` 覆盖、`spend_control`/`credits` 字段解析。

## 关键设计决策

- **不改数据库 schema**。`usage_providers.quota_source` 仍为单字符串;链逻辑封装在 `ClaudeChainCollector` 内部(collector 模式天然支持,`claude_quota.rs` 已有「一个 collector 内合并多来源」的先例)。新 collector 注册在 `"claude_local"` 这个 key 下替换 `ClaudeLocalQuotaCollector`,`quota.rs:776` 的 source 集合断言不变。
- **同意门控**(对标 CodexBar,简化版):
  - 新设置 `claude_keychain_consent_granted: bool` 默认 `false`,**升级绝不静默开启**,设置页可随时撤销;
  - 拒绝冷却:新设置 `claude_keychain_denied_until: Option<i64>`,系统钥匙串对话框被拒后 6 小时不再尝试;
  - 前置说明:开关打开前弹 `ConfirmDialog`(info 变体 + 未使用的 `checkboxLabel` 机制)解释读什么、为何读、如何撤销;
  - 仅 macOS 生效;非 macOS 时 OAuth 层返回「不可用」,链自动从 CLI 探测层开始。
- **CLI 探测节流**:调度器路径内最多每 30 分钟探测一次(内存闸门 + 失败启动闸门,参照 `claude_cli_auth.rs` 的 spawn 模式和 CodexBar 的 launch gate);手动刷新豁免。
- **429 处理**:Anthropic 该端点有限流,解析 `Retry-After`,本地记住 block 时间(默认 5 分钟),期间 OAuth 层直接判失败让链降级。

## 后端改动(src-tauri)

### 新增 `src-tauri/src/usage/claude_oauth.rs`
- `ClaudeOAuthCredentials`:`/usr/bin/security find-generic-password -s "Claude Code-credentials" -w` 读取(复用 `subscription.rs:205` 的 security CLI 模式,1.5s 超时),解析 `{"claudeAiOauth": {accessToken, refreshToken, expiresAt(ms), ...}}`。
- 同意闸门:`consent granted? → denied-cooldown? → read`,任何一步不过返回带 `CredentialStatus::ConsentRequired` / 明确错误文案的结果;**任何日志/错误中不出现 token**(沿用 allowlist 解析 + 既有 secrets 不落日志的测试惯例)。
- `fetch_claude_oauth_quota()`:`GET https://api.anthropic.com/api/oauth/usage`,headers:`Authorization: Bearer`, `anthropic-beta: oauth-2025-04-20`, `User-Agent: claude-code/<version>`;30s 超时;解析 `five_hour`/`seven_day` 窗口(`utilization` 即百分比 + `resets_at`),映射进 `SubscriptionQuota.tiers`;`seven_day_opus`/`seven_day_sonnet`/`extra_usage` 先存进 `raw_payload`(v1 不渲染,后续再加)。

### 新增 `src-tauri/src/usage/cli_probe.rs`(portable-pty)
- 新依赖:`portable-pty` 加入 `src-tauri/Cargo.toml`(经 `pnpm rust` 构建)。
- `probe_claude_usage()`:candidate-binary 解析复用 `claude_binary_candidates_for_home`;spawn `claude --allowed-tools "" --strict-mcp-config --session-id <uuid>`;等提示符后发送 `/usage`;轮询输出至出现百分比行或 `Failed to load usage data`;20s 超时杀进程组;解析 `Current session` / `Current week (all models)`(Opus/Sonnet 行顺手解析,同样入 raw_payload)。解析器为纯函数,可注入文本做测试(与 CodexBar 的 parse 测试同构)。

### 修改 `src-tauri/src/usage/quota.rs`
- 新增 `ClaudeChainCollector`(source = `"claude_local"`),顺序:OAuth → CLI 探测 → `collect_local_quota()`;每层失败记录原因,最终错误为不含机密的链摘要;替换 `legacy_collectors` 里的 `ClaudeLocalQuotaCollector`。

### 修改 `src-tauri/src/services/subscription.rs`(Codex 小补丁)
- `CredentialStatus` 增加 `ConsentRequired` 变体(`subscription.rs:19-26`)。
- legacy `codex` 路径:token 过期时用 CLI auth.json 里的 `refresh_token` 走 `auth.openai.com/oauth/token` 续期(复用 `codex_oauth_auth.rs` 已有刷新实现),失败才报 re-login。
- `query_codex_quota` URL 解析支持 `~/.codex/config.toml` 的 `chatgpt_base_url`(参照 CodexBar `parseChatGPTBaseURL`)。
- `CodexUsageResponse` 补 `spend_control.individual_limit` 与 `credits`(has_credits/unlimited/balance),映射进 tiers / raw_payload。

### 修改 `src-tauri/src/settings.rs`
- `AppSettings` 加两个字段:`claude_keychain_consent_granted`(bool, default false)、`claude_keychain_denied_until`(Option<i64>),照 `preserve_codex_official_auth_on_switch`(:423)的模式,自动走 `get_settings`/`save_settings` 到前端(camelCase)。

## 风险与注意事项

- macOS 钥匙串 ACL 会被 Claude Code 刷新时重写 → 系统对话框可能复现,由 6 小时拒绝冷却兜底。
- PTY 探测较重 → 30 分钟节流 + 仅在前层失败时触发;Anthropic OAuth 端点有限流 → 429/Retry-After 尊重。
- 新依赖 portable-pty 需走 `pnpm rust` 的 cargo 缓存包装;不在计划内跑全库 fmt。
- 按工作区记忆:在私有 `git worktree` 分支上实现,不碰 HANDOFF.md/.mimosa,不用 `git add -A`。
